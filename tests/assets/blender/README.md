# Blender MaterialX regression asset

`scene.usdc` and `textures/` were generated by Blender **4.5.3 LTS**, official
Windows x64 portable build `67807e1800cc`, using this repository's
`tools/blender_export_demo.py`. All geometry and textures are procedural original
test content under the repository license; no downloaded models are used.

The exporter uses `generate_materialx_network=True`, texture export with relative
paths, triangulated meshes and static transforms. Principled BSDF exports as
`ND_open_pbr_surface_surfaceshader`. The scene includes a textured/normal-mapped
coated sphere, anisotropic copper torus, ground, emissive meshes and a camera.

Recreate from the repository root:

```powershell
blender --background --factory-startup --python tools/blender_export_demo.py -- tests/assets/blender/scene.usdc
```

CTest compiles the original USD with the actual MaterialX/OpenUSD APIs, loads
the resulting self-contained package in the C++ renderer, then verifies GPU
rendering and optionally the DLSS interactive viewer. The compiled package is
generated under `build/`, outside version control.
