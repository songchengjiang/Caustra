# MaterialX feature gallery

All models are generated by `tools/blender_export_features.py`, using Blender
4.5.3 LTS (67807e1800cc); no downloaded meshes or textures are included.
`scene.blend` is the editable Blender scene, `blender_native.usdc` is its native
USD/MaterialX export, and `scene.usda` is the final portable composition.

The native export supplies clear, tinted, frosted and thin-walled glass test
geometry, subsurface wax, wool fuzz, thin-film metal, a volume cube, displacement
grid, ground and two emissive mesh lights. Blender exports the OpenPBR surface
lobes. The reproducible augmentation step adds explicit MaterialX volume and
displacement terminals, a true thin-walled flag, and a tinted-glass attenuation
distance. Those additions are authored USD overrides, not claims of native
Blender volume/displacement MaterialX export. `volume.mtlx` and
`displacement.mtlx` are editable standards-valid versions of those materials.

Run from the repository root (replace the Blender path for another install):

```powershell
./build/deps/blender-4.5.3-windows-x64/blender.exe --background --python tools/blender_export_features.py -- tests/assets/features/blender_native.usdc
./build/asset-tools-env/Scripts/python.exe tools/blender_export_features.py --augment tests/assets/features/blender_native.usdc
./build/asset-tools-env/Scripts/python.exe tools/compile_asset.py tests/assets/features/scene.usda build/feature-gallery.caustra --displacement-subdivisions 3
```

The final composition explicitly preserves the native export's meters-per-unit
and up axis. Volume coefficients use inverse world meters. Displacement is an
object-space scalar noise field evaluated into real microtriangles (3,200 at
the default subdivision level), with updated normals and bounds. Python tests
assert the actual imported lobe values, volume coefficients and changed geometry.
Source `.blend` retains the volume/displacement proxy objects; the explicit
terminals are in the paired USD/MaterialX files and augmentation script.
